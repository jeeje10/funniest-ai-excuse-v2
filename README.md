A one-line entry for make.fun's "The Funniest AI Excuse" bounty: the excuse an AI agent gives after failing a task. main.ts writes the excuse to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
